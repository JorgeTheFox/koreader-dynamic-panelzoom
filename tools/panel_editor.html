Como usar
  • Abra o .cbz (ou as imagens) e clique em Detectar todas: os quadros vêm pré-detectados com o mesmo algoritmo do plugin.
  • Arraste um quadro para movê-lo, as alças para redimensionar, ou arraste no vazio para desenhar um novo. Delete apaga o selecionado; setas ajustam de leve (com Shift, mais).
  • A ordem é o número no canto de cada quadro: use Antes/Depois ([ ]), Ordem automática, ou Definir ordem e clique nos quadros um a um.
  • PageUp/PageDown mudam de página. Ctrl+Z desfaz. O progresso fica salvo neste navegador.
  • Exportar JSON gera nome_do_quadrinho.json: copie para a mesma pasta do quadrinho no leitor. Páginas sem quadros no arquivo usam a detecção automática do plugin.
